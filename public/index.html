TRD Platform Handbook

操作说明书

外贸应收、成本、物流与退税资料协同平台使用指南

当前版本：v2.0 适用对象：业务 / 财务 / 成本 / 物流 / 管理员 更新时间：--
一票业务 一个订单贯穿应收、成本、物流、退税和归档
应收订单建立一票业务主索引
收款管理登记客户实际回款
成本管理录入并确认各类费用
国内物流信息填写首程运输资料
退税资料汇总单证与发票
提交退税完整度 100% 后提交
自动归档移入退税档案
档案查询随时调取历史资料
重要规则

提交退税前必须总体完整度 100%

  • 已提交退税后，订单自动归档。
  • 归档不是删除，所有数据和附件完整保留。
  • 已归档业务可在退税档案和报表中心随时调取。
  • 退税归档不代表收款完成，收款管理不因退税归档而隐藏。
01系统定位

本系统用于管理外贸业务从应收订单、客户回款、成本录入、国内物流资料、退税资料收集，到退税提交和资料归档的全过程。

核心原则

一票业务 = 一个订单。所有收款、成本、物流资料、退税资料都必须围绕订单进行管理。

模块入口

从左侧菜单进入应收订单、收款管理、成本管理、国内物流信息、退税资料和报表中心。

02业务流程

标准流程用于保证订单、资金、成本、资料和档案之间不断链。

  1. 建立应收订单
  2. 登记客户回款
  3. 录入成本费用
  4. 录入国内物流信息
  5. 汇总退税资料
  6. 检查总体完整度
  7. 提交退税
  8. 自动归档
  9. 后续在档案中查询
03应收订单

业务员负责创建应收订单。订单是后续收款、成本、物流、退税资料的唯一业务主线。

主要填写
  • 客户名称、订单号、提单号
  • 币种、汇率、预计应收金额、最终应收金额
  • 付款条款、预计发货日期、提单日期、到期日、订单状态
注意事项
  • 订单号必须唯一。
  • 客户名称统一大写。
  • 币种来自客户资料或手动选择。
  • 后续收款、成本、物流、退税都会关联该订单。

相关入口：应收订单

04收款管理

财务负责登记客户实际回款，系统根据已到账收款自动更新订单回款状态。

支持类型
  • 预付款
  • 尾款
  • 补差款
  • 其他收款
系统自动计算
  • 已收金额、未收金额、多收金额
  • 回款率、是否逾期
  • 退税归档不会影响收款管理。

相关入口：收款管理

05成本管理

成本管理用于记录每票订单产生的全部费用，成本确认后进入利润分析和相关资料完整度计算。

成本包括
  • 工厂货款、拖车费、报关费、港杂费、海运费
  • 银行手续费、国外佣金、样品费、其他费用
注意事项
  • 所有成本必须关联订单。
  • 成本确认后才进入利润分析。
  • 发票状态会影响退税资料完整度。
  • 默认只显示当前业务，已归档业务可通过筛选查询。

相关入口：成本管理

06国内物流信息

物流资料录入员、业务员或管理员填写国内首程运输信息，并上传报关资料。

主要内容
  • 运输方式、起运地、到达地
  • 运输货物名称、起运日期
  • 车牌号或快递单号
  • 出口发票备注
上传资料
  • 报关单
  • 放行通知书
  • 报关委托书
  • 上传后自动归属订单并进入退税资料统计。

相关入口：国内物流信息

07退税资料

退税资料模块用于按订单汇总出口退税所需资料，列表只保留总体完整度，详细资料在查看资料中展开。

系统汇总
  • 出口资料：销售合同、发票、提单、报关单、放行通知书、报关委托书
  • 工厂资料：工厂合同、工厂发票
  • 物流资料：报关费发票、拖车费发票、港杂费发票
注意事项
  • 退税资料只保留总体完整度。
  • 缺失资料需要回到对应上传区域补齐。
  • 总体完整度不足 100% 时不能提交退税。

相关入口：退税资料

08提交退税与归档

提交退税必须满足总体完整度 = 100%。如果资料不足，系统会阻止提交并提示缺失资料。

提交后系统自动执行
  • 状态变为已提交退税。
  • 订单自动归档。
  • 从退税资料当前列表、成本管理当前业务、国内物流当前业务和经营总览待处理提醒中隐藏。
归档说明
  • 归档不是删除。
  • 归档后的订单可在退税档案、报表中心、已归档业务筛选中查询和调取。
  • 退税归档只代表资料链完成，不代表货款已经收齐。
  • 收款管理不受退税归档影响。

相关入口：退税资料 → 查看资料 / 提交退税 / 退税档案

09报表中心

报表中心用于在线查询和按需下载业务数据，日常查询默认当前业务，历史查询可选择已归档业务或全部业务。

支持报表
  • 应收订单明细、收款明细、成本明细
  • 利润分析、业务员提成、逾期催款、退税资料
业务范围
  • 当前业务
  • 已归档业务
  • 全部业务

相关入口：报表中心

10系统设置

管理员维护基础资料、权限和系统口径。系统设置中的变更会影响业务数据展示和权限边界。

可维护内容
  • 汇率设置、客户资料、供应商资料
  • 用户与权限、操作日志
注意事项
  • 汇率影响所有外币折人民币金额。
  • 客户资料中的业务员和提成比例会影响利润与提成统计。
  • 用户权限决定能看到哪些模块。
  • 操作日志用于追溯关键修改。

相关入口：系统设置

11日常注意事项
  1. 订单号、客户、币种、金额、付款条款保存前必须核对。
  2. 所有收款、成本、物流、退税资料必须关联订单。
  3. 成本未确认时，不应进入最终利润结算。
  4. 总体完整度不足 100%，不允许提交退税。
  5. 已提交退税后自动归档。
  6. 归档不是删除，只是放入档案室。
  7. 已归档业务可随时调取。
  8. 收款未完成不影响退税归档。
  9. 退税归档不等于订单关闭。
  10. 任何关键修改都必须写入操作日志。
