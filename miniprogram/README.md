# NEXTWOOD RMB 小程序

这是 RMB 的统一移动端入口，与 RMB 网页端共用账号、会话、角色权限和业务数据。

当前功能：

- 所有已启用、已审核的现有 RMB 账号统一登录
- 按账号角色与自定义权限显示业务模块
- 客户档案与报价查询、报价详情、新建和编辑报价草稿
- 销售执行查询、详情和直接创建（含工厂采购分配）
- 应收订单查询、详情和订单草稿创建
- 产品供应商可查询工厂采购单、回复价格和交期、填报生产进度
- 有资料回传权限的账号可查询任务并上传 PDF
- 尚未原生接入的模块会明确提示在 RMB 网页端使用

## 开发者工具

1. 在微信开发者工具中导入本目录。
2. AppID 已配置为 `wx1f1d7b39c44c7949`。
3. 正式环境需将 `https://www.nextwood.net` 配置为 request、uploadFile 和 downloadFile 合法域名。
4. 本地调试其它后端时，在开发者工具 Storage 中设置 `rmbMiniApiBaseUrl`。

小程序不保存密码，只在 Storage 中保存服务器签发的会话令牌。
