# NEXTWOOD 内部物流小程序

该目录是一套独立的原生微信小程序。它不会替换或关闭现有微信公众号；公众号和小程序使用各自的 AppID、AppSecret、OpenID、订阅授权和发送队列。

## 上线前配置

1. 在微信公众平台创建小程序并取得小程序 AppID、AppSecret。
2. 在“小程序后台 → 开发管理 → 开发设置 → 服务器域名”把 `https://www.nextwood.net` 加入 request 合法域名。
3. 选择一个“物流状态更新”类一次性订阅消息模板，记录模板 ID 和字段名。
4. 通过 NEXTWOOD 管理接口 `/api/settings/wechat-mini` 保存 AppID、AppSecret、模板 ID 与字段名，或配置对应的 `WECHAT_MINI_*` 环境变量。
5. 用微信开发者工具导入本目录，把 `project.config.json` 的 `appid` 替换为真实小程序 AppID。
6. 完成真机测试后，在微信开发者工具上传代码，并在小程序后台提交审核、发布。

## 模板字段

默认字段为：订单号 `thing1`、物流状态 `phrase2`、节点时间 `time3`、节点说明 `thing4`。实际模板字段必须以微信后台显示的字段名为准，可通过设置接口修改。

## 登录与权限

员工首次登录需要微信临时登录码以及 NEXTWOOD 网页系统邮箱、密码。服务端只保存微信 OpenID 和会话令牌哈希，不保存明文密码或微信 session_key。管理员可查看全部授权物流，业务员仅能查看自己负责订单，规则与网页端一致。

## 订阅消息限制

小程序一次性订阅消息必须由用户主动点击授权。每次接受通常只产生一次可发送额度；发送后需再次授权。系统会显示剩余授权次数，并在物流变化时同时保留原邮件、公众号发送流程。
