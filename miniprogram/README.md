# NEXTWOOD RMB 小程序

这是 RMB 的统一移动端入口，与 RMB 网页端共用账号、会话、角色权限和业务数据。

当前功能：

- 所有已启用、已审核的现有 RMB 账号统一登录
- 按账号角色与自定义权限显示业务模块
- 客户档案与报价查询、草稿版本、报价邮件、PDF 附件和线下确认登记
- 销售执行查询、直接创建、工厂采购分配、草稿编辑、正式下发和作废
- 应收订单查询、新建、编辑、删除草稿及订单收款联动
- 收款、成本、利润、物流信息、客户沟通、运输监控和物流费用
- 产品供应商可查询工厂采购单、回复价格和交期、填报生产进度
- 有资料回传权限的账号可查询任务并上传 PDF
- 退税资料、九类经营报表、移动操作手册和管理员设置状态
- 成本、物流信息和物流费用可在小程序直接新增业务记录

登录页是所有 RMB 角色共用的统一入口，不再以供应商身份命名。页面和操作仍按服务端角色、菜单、读写权限及数据范围进行裁剪；供应商能力只是统一入口中的一部分。

涉及邮件、短信、OCR、Freightower 等密钥的配置不会向小程序返回明文，继续在受控网页端维护。

## 开发者工具

1. 在微信开发者工具中导入本目录。
2. AppID 已配置为 `wx1f1d7b39c44c7949`。
3. 正式环境需将 `https://www.nextwood.net` 配置为 request、uploadFile 和 downloadFile 合法域名。
4. 本地调试其它后端时，在开发者工具 Storage 中设置 `rmbMiniApiBaseUrl`。

小程序不保存密码，只在 Storage 中保存服务器签发的会话令牌。
